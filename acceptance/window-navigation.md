# WindowNavigationIndex：Phase 0 验收规格

对应 [#150](https://github.com/mist-agent-harness/mist-agent/issues/150) 与
[设计图](../docs/design/window-navigation-index-phase-0.md)。全部未勾选；本页是
未实现、未运行的语义规格，不能称为「已经运行失败的测试」，也不接入现有第一里程碑
runner。实现单须先写可执行红测试，再以真实 adapter 和宿主证据点灯。

## 判卷方式

只用公开合成语料与生成的临时宿主数据，不使用任何真实住户人格、记忆或聊天。
比较调用轨迹、handle 字段、hash、scope、水位、版本、计数与真实副作用，不判
「看起来像」。重建判卷必须真实删除索引再从权威真源重建，不接受内存复位冒充；
停机判卷必须真实停掉索引服务；集成不得让 mock 直接返回期望的候选或回执。

## 灯

| 灯 | 合成输入与操作 | 层级 | 可观察通过判据 |
| --- | --- | --- | --- |
| NI-01 | 固定权威真源建索引并收录命中样本；真实删除索引后从真源全量重建 | 集成 | 重建前后同一查询的已收录 hit 之 handle 指向同一权威记录并可精确回源；没有可服务 snapshot 时查询返回结构化 unavailable、不冒充零命中（「重建期一律停查」是额外策略，实现选它须单列决定与代价） |
| NI-02 | 注入索引停机、库损坏、水位落后；对照组在无索引故障下执行相同的合法读写与换气序列 | 集成 | 与对照组比较，索引故障未给权威侧带来任何额外副作用——字节、序号与状态差异仅来自合法操作本身；导航仅降级；恢复后不存在补写权威的行为 |
| NI-03 | 双世界仅差一条跨 resident／跨 scope 的不可披露记录；同时检查投影内容与 adapter 调用轨迹 | 集成 | 同一获准查询在两世界的候选、计数、摘要、错误与回执逐项一致；投影中不存在禁止入索引的内容（闸一真在入库前）；实际 adapter 调用范围未越界后再过滤（闸二在检索侧而非结果侧）；无名称、数量或存在暗示 |
| NI-04 | 命中样本建立后暂停在候选阶段，执行撤权／supersede／撤回／归档，再分别回源与读缓存 | 集成 | 旧 hit 不再越权可见；撤权或当前 policy 禁止读取时，回源与缓存均不得带出内容；仍获准且原始版本可核证的记录，可以作为历史证据读取——supersede 不自动等于旧记录不可读；归档记录是否可取证按权威 visibility policy 判——policy 允许时归档记录仍可命中，索引不自行判隐藏 |
| NI-05 | 分别注入 source 缺失、hash 不符、序列化版本漂移 | 集成 | 不返回陈旧 snippet 代替原文；三种失败结构化可分；同一内容同一序列化版本不产生假损坏 |
| NI-06 | 冻结 corpus＋查询集＋标注 relevant source handles，含必命中的精确词法正例与零命中反例；两次独立运行 | 单元＋集成 | 正例必命中、反例零命中；候选集合与排序两次一致，或声明的非确定因素在回执可见；记录相对标注集的实际读数，不预设 magic threshold |
| NI-07 | 完成一次查询后检查全部写入面；再分别观察显式调用、回源、注入成功与注入被拒／取消／失败 | 集成＋静态 | 索引不自行写记忆、事实账、权威业务记录或下一窗 prompt；宿主经既有唯一 writer 持久化受权限约束的控制回执不在禁止之列（#152 保留路径）；显式调用、回源、实际注入是三张分开的回执；只有获得授权且实际注入成功，才允许注入成功回执——未执行、被拒、取消或失败不得冒充成功，对应尝试可留痕 |
| NI-08 | 分别喂 handoff 标题／精确回源的 event chunk／带稳定 eventId 与原始事件指针的权威 typed 摘要／索引自产摘要／仅有 summary 标签而无可核证指针的摘要 | 单元＋集成（真实 ingest adapter，可共享 NI-01 重建夹具） | 前三收录、后二拒收且拒收可观察；typed 标签本身不构成准入 |
| NI-09 | 构造三域 handle；分别尝试来源域错配、事件范围错配、hash 校验对象错配的解析 | 单元＋静态 | handle 为版本化 discriminated union，按 sourceDomain 分发；拒绝的是来源域、事件范围、hash 校验对象的错配，不因数值恰好相同而拒；每个 handle 可辨 hash 校验对象与序列化版本 |
| NI-10 | 多事件 chunk 命中；分别以单 eventId 背书整段、使范围内一条事件失效 | 单元＋集成（范围失效支可与 NI-04／05 共享夹具） | chunk handle 声明完整 seq range／event-id list；单 eventId 背书多事件 snippet 判红；范围内任一事件失效时该 hit 的可信状态可见 |
| NI-11 | 真实停掉索引服务后查询 | 集成 | 返回结构化 unavailable 且带降级原因；不得返回正常空结果冒充零命中 |
| NI-12 | 分别构造 top-k 截断与分页未完 | 单元＋集成 | 回执中保留数与展示数分开；完整覆盖状态不为真；任何一层完整不替其他层背书 |
| NI-13 | 构造索引落后于真源（新写入未入索引） | 集成 | 回执报目标水位与已索引水位；落后／未知不冒充已追齐；新记录查不到可由水位差解释 |
| NI-14 | 翻页中途更新索引，分两支：一支保留原 snapshot 可读，一支使原 snapshot 不可读 | 集成 | 可读支：旧 cursor 按原快照继续分页，且重新过当前权限闸；不可读支：显式失效，不静默串到新 snapshot |
| NI-15 | 源侧真实执行切块、压缩、迁移使 path/line 漂移 | 单元＋集成（漂移由真实操作产生，可共享 NI-01 夹具） | 漂移的 locator 不作回源依据；回源仅认 handle 重新解析；对旧 locator 的使用被拒且可观察 |
| NI-16 | 正常查询、降级查询各取回执比对；另在隐藏 scope 追加新记录后重取 | 单元＋集成 | 每份召回回执含 projection/index version、policy version、目标与已索引水位、截断／降级原因；版本变化跨查询可比；水位与版本按获准 scope 披露，隐藏 scope 的新增不改变可见回执（与 NI-03 双世界合并检查） |
| NI-17 | 对 handle A 解析／回源失败后，执行改 query／handle／范围／snapshot 的成功尝试 B | 集成 | A 的失败回执保留且状态不变为已恢复；同一 handle 的后续成功须显式关联才构成恢复证据；索引层不产生 episode 结案状态（结案语义归 #152 SE-11） |
