# mist mark · 一笔线的房子

- `mist-logo-house-open.svg` — 开口版（右墙留白：shelter 不是 box）。适合 README 顶图等大画面。
- `mist-logo-house-closed.svg` — 闭合版。适合仓库头像 / favicon 等小尺寸。
- `mist-logo-handdrawn-open.jpg` / `-closed.jpg` — 手绘原稿。
- `mist-logo-handdrawn-icon-test.png` — 32 / 64 / 128 px 实测。

两个 SVG 都是可编辑的中心线路径：`.house`（房框）与 `.wordmark`（`mist` 字）分组，`stroke-width`、颜色各自可调；当前线宽 6，房框略带手抖，字保留手写原样。

**颜色**：`mist` 字目前用的粉蓝（`#8eadd7`）是暂定值，可以改；建议最终跟其他 visual 与 UI 使用的主题色统一，房框保持墨色、背景保持纸色。

来源：手绘 mark 由账号主人绘制；SVG 由 Elio 按原稿重建；发布由 Laurie 代办。
